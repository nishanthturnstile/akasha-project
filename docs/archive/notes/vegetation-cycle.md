# **1. What is vegetation cycle?**

The **vegetation cycle (crop cycle)** is the **full life period of a crop** from planting to harvest.

### It includes stages like:

```
Sowing → Germination → Growth → Flowering → Fruit/Grain → Maturity → Harvest
```

👉 Example (Rice):

* Sow seeds in June
* Harvest in October  
  ➡️ Total cycle = \~120 days

***

# **2. Difference between “crop name” and “group name”**

You mentioned “group name (above level) vs crop name”. Here's the difference:

### ✅ **Group name (Higher level / category)**

This is a **broad classification of crops**.

Examples:

* Cereals
* Pulses
* Oilseeds
* Vegetables

***

### ✅ **Crop name (specific crop)**

This is the **actual crop within that group**.

Examples:

| Group    | Crop Name            |
| -------- | -------------------- |
| Cereals  | Rice, Wheat, Maize   |
| Pulses   | Chickpea, Green gram |
| Oilseeds | Groundnut, Sunflower |

***

👉 So:

* **Group = category**
* **Crop name = specific plant**

***

# **3. Variety, maturity, cut-off date, sowing & harvesting date**

These are all crop planning details:

***

### ✅ **Variety**

Different types of the same crop.

Example (Rice):

* Basmati (long grain, aromatic)
* IR64 (high yield)

Each variety differs in:

* Growth duration
* Yield
* Disease resistance

***

### ✅ **Maturity**

The **time required for crop to be ready for harvest**.

Example:

* Short duration: 90 days
* Medium: 120 days
* Long: 150 days

***

### ✅ **Sowing date**

Date when the crop is planted.

***

### ✅ **Harvesting date**

Date when crop is collected.

***

### ✅ **Cut-off date**

Important in planning, schemes, or systems.

👉 It means:

* The **last allowed date** for sowing or reporting
* Used in insurance, government programs, or data systems

***

### Example timeline:

```
Sowing: June 1
Cut-off sowing: June 30
Harvest: October 15
```

***

# **4. What is irrigation type and tillage type?**

***

## ✅ **Irrigation type**

How water is supplied to crops.

### Common types:

* **Flood irrigation** → Water fills entire field (rice)
* **Drip irrigation** → Water directly to roots (water-saving)
* **Sprinkler irrigation** → Water sprayed like rain

***

## ✅ **Tillage type**

How soil is prepared before planting.

### Types:

* **Conventional tillage** → Deep ploughing
* **Minimum tillage** → Less disturbance
* **Zero tillage** → No ploughing

***

👉 Purpose:

* Improve soil condition
* Control weeds
* Help root growth

***

# **5. Target yield vs Actual yield**

***

## ✅ **Target yield**

* Planned or expected output
* Based on ideal conditions

👉 Example:

* Target = 5 tons per hectare

***

## ✅ **Actual yield**

* Real output after harvest

👉 Example:

* Actual = 4 tons per hectare

***

## ✅ Why they differ?

* Weather (rain/drought)
* Pests or diseases
* Soil fertility
* Farming practices

# **7. Database Schema**

## **Master / Reference Tables**

```python

irrigation_type
├── id             PK, serial
└── name           varchar(100)

tillage_type
├── id             PK, serial
└── name           varchar(100)
```

## **Core Config Tables**

```python
crop
├── crop_id                     PK, serial
├── name                        varchar(255)
├── has_variety                 boolean, default false
├── has_maturity                boolean, default false
├── has_planting_cutoff_date    boolean, default false
└── maturity_options            text[]        ← e.g. {"early","mid","long"}

variety
├── variety_id                  PK, serial
├── name                        varchar(255)
├── crop_id                     FK → crop.crop_id
└── maturity_options            text[]        ← e.g. {"default","early","mid"}
```

## **Transaction Table**

```python
vegetation_cycle
├── vegetation_id               PK, serial
├── crop_id                     FK → crop.crop_id
├── variety_id                  FK → variety.variety_id, nullable
├── maturity                    varchar(50), nullable   ← selected from maturity_options
├── sowing_date                 date, nullable
├── planting_date               date, nullable          ← used if has_planting_cutoff_date
├── is_cutoff_start_date        boolen, nullable
├── harvest_date                date, nullable
├── irrigation_type_id          FK → irrigation_type.id, nullable
├── tillage_type_id             FK → tillage_type.id, nullable
├── target_yield                decimal(10,2), nullable
├── actual_yield                decimal(10,2), nullable
├── field_id                    FK → field.field_id
├── season_id                   FK → season.season_id
├── notes                       text, nullable
├── user_id                     FK → users.id
├── created_at                  timestamp
└── updated_at                  timestamp
```

## **Field Visibility Rules (App Logic)**

- `has_variety = True` → show variety dropdown; `variety_id` required
- `has_maturity = True` → show maturity dropdown (filtered by `variety.maturity_options` if variety selected, else `crop.maturity_options`)
- `has_variety = False` and `has_maturity = True` → `maturity` required directly
- `has_planting_cutoff_date = True` → show `planting_date` instead of `sowing_date`
- All other fields except crop name + date field are optional
